Privacy policy

Lucky backup is used only by its owner, with the owner's own Google account. It is not offered to anyone else.

Google user data it accesses

Through the Google Drive API with the drive.file permission, it creates, reads, updates and deletes only the backup files it uploaded itself to the owner's Google Drive. It cannot see any other file in that Drive.

How the data is used and stored

The backup files are encrypted on the owner's computer before upload and are used only to restore the owner's own data. The access token is stored only on the owner's computer.

Sharing

No data, including Google user data, is collected, shared, sold or transferred to anyone. Nothing is used for advertising or analytics.
